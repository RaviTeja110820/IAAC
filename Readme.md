# 🚀 Infrastructure as Code (IaC) Projects using Terraform

## 📖 Overview

This repository contains a collection of hands-on Infrastructure as Code (IaC) projects built using **Terraform**, demonstrating best practices for cloud infrastructure provisioning, environment management, CI/CD automation, and Kubernetes monitoring.

The projects are designed to showcase practical DevOps skills, including reusable Terraform modules, multiple environment management using workspaces, infrastructure automation through Jenkins, and monitoring Kubernetes clusters with Prometheus and Grafana.
